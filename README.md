# CutLab

ブラウザだけで動く、無料の画像切り抜きツールです。画像データは外部サーバーへ送信せず、すべてローカルのブラウザ内で処理します。

## 主な機能

- 画像のドラッグ＆ドロップ読み込み
- 四角形切り抜き
- 多角形切り抜き
- 残すブラシ / 消しゴム / 復元
- クロマキー
  - スポイト
  - Green / Blue / White / Black プリセット
  - 許容値
  - エッジ調整
  - 背景と連続した領域だけを削除
  - 色かぶり軽減
- Undo / Redo
- ズーム / パン
- 透明チェッカー
- マスク確認表示
- 透過PNG書き出し

## GitHub Pages で公開する方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の `index.html`、`styles.css`、`app.js`、`README.md` をリポジトリ直下へアップロードします。
3. GitHubのリポジトリで **Settings → Pages** を開きます。
4. **Build and deployment** の Source を **Deploy from a branch** にします。
5. Branch を `main`、フォルダを `/ (root)` にして Save します。
6. 少しすると `https://ユーザー名.github.io/リポジトリ名/` で公開されます。

## 操作

- 画像読み込み: 上部「画像を開く」またはドラッグ＆ドロップ
- パン: 「移動」ツール、または Space + ドラッグ
- ズーム: マウスホイール / スライダー
- 多角形: クリックで点を追加、ダブルクリックで確定
- クロマキー: スポイトで背景色を選び、プレビュー → 適用
- Undo: Ctrl/Cmd + Z
- Redo: Ctrl/Cmd + Shift + Z

## 補足

現在の版は静的Webアプリです。AI背景除去のように巨大なモデルを必要とする機能は含めていませんが、クロマキー・マスク編集・手動切り抜きは完全にブラウザ内で利用できます。
